## Targeted comparison-table page

The comparison table appears on page 23 as an editable LaTeX table with the caption above it, consistent with De Gruyter conventions. It is readable at review size, but very dense: several long cells wrap tightly, especially the architecture, main contribution, and remark columns. This is acceptable for a review submission but should be checked after any final text edits.

The table caption is concise and self-explanatory. The table uses horizontal rules and no shading or vertical rules. Units are included in column headings or cell text. The final row clearly identifies the single-element nature of the present work and avoids claiming array enhancement.

The comparison table is deferred to the final page by float placement. This is not a compilation error, but it is not ideal for reader flow. The authors can either retain it as an end-of-manuscript table for initial review or use an explicit placement marker such as `[Place Table 5 near here]` if required by the journal workflow.

No graphical abstract is present in the current Frequenz conversion because the Radio Science source used for this conversion does not contain the separately prepared AEU graphical abstract. If Frequenz submission requires or permits a graphical abstract, it should be added as a separate submission asset only after confirming the journal portal requirement.
