# Shared manuscript assets

This directory contains the curated figure files used by the manuscript versions. Source numerical data remain in the repository-level `figure_data/` directory. Files in this directory are named to match the LaTeX sources and avoid fragile references to spaces or obsolete filenames.

The AEU graphical abstract is retained here as an AEU-specific asset; it is not inserted into the Frequenz or Radio Science versions unless the target journal requests it.
